# Personal Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript to showcase my academic background, technical skills, projects, and certifications.

## Overview

This project serves as my professional online portfolio, providing a central place to explore my work, technical interests, and academic achievements.

## Features

- Responsive website layout
- Professional profile and introduction
- Technical skills and project showcase
- Education and certifications
- Contact and professional profile links
- Interactive elements and visual styling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Project Structure

```text
shela-portfolio/
├── assets/
│   └── certificates/
├── profile.jpg
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/shaidun/shela-portfolio.git
   ```

2. Open the project folder in your preferred code editor.
3. Open `index.html` in your browser.

Alternatively, start a local server using Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

- **Website content:** Edit `index.html`.
- **Design and layout:** Edit `style.css`.
- **Interactive functionality:** Edit `script.js`.
- **Profile image:** Replace `profile.jpg` with your updated image, keeping the filename and location unchanged.
- **Certificates:** Add PDF files to `assets/certificates/` and update the corresponding links in the HTML file.

## Deployment

This static website can be hosted using GitHub Pages.

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the publishing branch, usually `main`, and select `/(root)`.
5. Save and wait for the deployment to complete.
